# EX. No.3.1. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION

## AIM:
To create a 3D model from given orthographic projection.

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:

## Step 1 
Select the top view and create a sketch. Draw an outer rectangle and then draw the U-shaped profile using the Line tool. Set the thickness of the upper and lower arms to 11 mm. The gap between the two arms is 18 mm. The overall length of the main body is 52 mm. Extrude the sketch by 32 mm.

- Select the XY plane to create the sketch.
- Use the Line and Rectangle tools to draw the required profile.
- Check all dimensions before finishing the sketch.
- Click Finish Sketch and apply the Extrude command.
<img width="292" height="487" alt="image" src="https://github.com/user-attachments/assets/2dff49a8-b913-41ac-81ac-e993456de391" />

## Step 2 
Select the right side view and draw a circle of diameter 18 mm inside the rectangle. Extrude the circle by 32 mm.
- Select the correct face for sketching.
- Use the Circle tool to draw a circle.
- Apply the required diameter of 18 mm.
- Finish the sketch and extrude the circular profile by 32 mm.

<img width="312" height="172" alt="image" src="https://github.com/user-attachments/assets/6766790c-62a0-437d-9603-9482bab239fb" />

## Step 3
Select the right side view and draw a circle of diameter 16 mm at the centre, at a distance of 32 mm from the side of the rectangle. Extrude the circle by -72 mm.

- Use the Sketch Dimension tool to set the circle diameter.
- Position the circle at the required centre location.
- Select the circular profile carefully.
- Apply the Extrude command with -72 mm.
## Step 4
After creating the hole, select the Fillet option, pick the two corners of the left arm and the two corners of the right arm, and apply a fillet of 16 mm.

- Open the Modify menu and select Fillet.
- Select the four required outer corners.
- Enter the fillet radius as 16 mm.
- Check the rounded edges of the model.

# <img width="278" height="446" alt="image" src="https://github.com/user-attachments/assets/8ab30588-e16b-42cd-bb37-69b5eaa51199" />

## Step 5
Once done, go to Design, choose Drawing and select From Design. Place the front view, top view, side view and isometric view on the sheet.

- Select Drawing from the Design workspace.
- Choose the From Design option.
- Set the drawing standard to ISO.
- Select units as mm and sheet size as A3.
- Arrange all four views properly on the drawing sheet.
